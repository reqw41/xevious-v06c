# Локальное сравнение звука CPC и Вектора

Нужны Node.js, исходный `ref/cpc/xevious.dsk` и уже собранные `build/xevious.rom`,
`build/xevious.json`, `build/gen/vec_sound.inc`. Команды запускаются из корня проекта:

```sh
node tools/snd/compare.js
node tools/snd/check.js
# Отдельно снять два прохода одной мелодии, без игры:
node tools/snd/capture.js --song 4800
```

Весь результат находится в `build/snd/compare/`: три набора `*_ay.wav`, `*_vi53.wav`,
`*_both.wav`, эффекты `fx_both.wav`, русский `LIST.md`, исходные регистры и журналы OUT,
`manifest.json` с контрольными суммами входов, `checks.json` с результатами проверок.
Стерео: AY слева, ВИ53 справа; PCM 16 бит / 44,1 кГц, шаг проигрывателей 50 Гц.
Существующие инструменты, ROM и генератор серий не изменяются и не перезапускаются.

`capture.js` исполняет оригинальный Arkos в банке 4 модели CPC, без загрузки и шагов игры.
`ay.js` синтезирует звук отдельно, учитывая реальные записи R13, включая повторные.
`vi53.js` вызывает настоящий проигрыватель существующего ROM на модели i8080, проверяет
его делители независимым декодером серий и рендерит журнал портов моделью ВИ53 vector06js.
`audio.js` фильтрует и записывает PCM, `compare.js` собирает пары и список.

Заставка жизни у CPC имеет петлю 336 кадров, но в ROM Вектора поток конечный — 300 кадров.
Для неё в правом канале после конца потока оставлена тишина. Конец игры и ввод имени —
один модуль 4C00h. В фоне и конце игры компенсируется один пустой кадр старого захвата
`vecsound.js`; сдвиг подтверждается сравнением делителей и записан в JSON.
У эффектов сохраняется полсекунды хвоста фильтров после конца звука.

Модель цифровая, с приближённой логарифмической громкостью AY, без аналогового тракта.
Частоты/формы огибающей сверены с
[MAME ay8910](https://github.com/mamedev/mame/blob/master/src/devices/sound/ay8910.cpp).
Усиление одинаковое для обоих чипов, отдельные файлы не нормализуются.

Проверки включают 16 форм огибающей и повторный R13, микшер R7, полный период шума,
частоты обоих чипов и готового PCM, последовательности портов/серий ROM, синхронизацию
с CPC, формат/длины WAV, отсутствие клиппинга и побайтовое совпадение стереоканалов с моно.
